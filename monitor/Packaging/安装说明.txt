Agent Watch {{PRODUCT_VERSION}} / build {{BUILD_NUMBER}}
========================================================

适用环境
--------
- 系统要求：macOS {{MINIMUM_OS}} 或更高版本
- 芯片架构：{{ARCHITECTURE}}（仅支持 Apple Silicon arm64）
- 运行引擎：内置原生 Rust 引擎（v{{BACKEND_VERSION}}）与 Seatbelt 隔离网关，无需预装 Python
- 签名说明：本安装包采用本机临时签名（ad-hoc），未经过 Apple Developer ID 公证

安装与首次使用（纯拖拽，无需命令行）
------------------------------------
1. 打开本磁盘映像，直接将「Agent Watch.app」拖入旁边的「Applications（应用程序）」文件夹。
2. 从「应用程序」中双击打开 Agent Watch：
   - 若首次打开遇到系统未公证拦截，请在「系统设置 › 隐私与安全性」中点击允许，或右键应用选择「打开」。
   - 首次初始化向导会自动引导完成辅助功能授权，并在第 3 步通过图形界面一次性安装后台采集任务与本地 Seatbelt 网关（全程只需输入一次管理员密码，后续改时区/关 IPv6/日常使用均不再反复弹窗）。
   - 不会擅自启动 Claude / ChatGPT / Codex，也不会修改 TAG 或其他代理软件配置。
3. 后续升级无需手动下载 DMG：可直接在应用内「后台保护」页点击「检查更新 / 下载并安装更新」，通过 RSA-4096 签名校验自动完成原地升级，保留全部账号与配置。

卸载方法
--------
- 双击运行本磁盘映像中的「卸载应用.command」，或在终端执行：
  "/Applications/Agent Watch.app/Contents/Resources/watch-engine" app-uninstall --apply
- 卸载仅移除 Agent Watch 应用与自有后台任务并清理其辅助功能授权；原生 Claude / ChatGPT / Codex、登录数据、TAG 配置及独立原版工具均不受影响。
